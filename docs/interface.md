# Xiangqi 项目接口统一文档



## 1. 坐标统一约定

象棋棋盘统一为：

| 项目         | 约定                |
| ---------- | ----------------- |
| 棋盘大小       | 10 行 × 9 列        |
| x          | 列坐标，范围 0 到 8，从左到右 |
| y          | 行坐标，范围 0 到 9，从上到下 |
| 左上角        | x = 0, y = 0      |
| 右下角        | x = 8, y = 9      |
| 一维索引       | index = y × 9 + x |
| C++ 二维数组访问 | board[y][x]       |

所有模块统一使用：

```text
x 表示列
y 表示行
board[y][x] 表示棋盘数组访问
```



## 2. 棋子编码统一约定

棋子数据拆成两个部分：

```text
side：阵营
type：棋子类型
```

### 2.1 阵营 side

| side 数值 | 含义 |
| ------- | -- |
| 0       | 空  |
| 1       | 红方 |
| 2       | 黑方 |

### 2.2棋子类型 type

| type 数值 | 含义    |
| ------- | ----- |
| 0       | 空     |
| 1       | 将 / 帅 |
| 2       | 士 / 仕 |
| 3       | 象 / 相 |
| 4       | 马     |
| 5       | 车     |
| 6       | 炮     |
| 7       | 兵 / 卒 |
