# Xiangqi - Qt6 中国象棋

## 1. 项目简介

本项目是基于 Qt6 开发的中国象棋桌面应用，使用 QML 和 C++ 混合编程实现。

界面部分使用 Qt Quick / QML 编写，棋盘数据、象棋规则、游戏控制和局域网通信使用 C++ 实现。

项目支持本地对弈和局域网联机对弈。

---

## 2. 主要功能

* 显示中国象棋棋盘
* 显示红黑双方棋子
* 支持点击选择棋子
* 支持棋子移动
* 支持吃子
* 支持非法走法提示
* 支持红黑双方轮流走棋
* 支持重新开始本地棋局
* 支持创建局域网房间
* 支持输入 IP 加入房间
* 支持双方走棋同步
* 支持显示连接状态
* 支持显示玩家身份
* 支持断开连接

说明：联机模式下，如果需要重新开始，双方都需要点击“重新开始”。

---

## 3. 使用说明

### 3.1 本地对弈

1. 启动程序后进入中国象棋主界面。
2. 红方先行。
3. 点击己方棋子进行选择。
4. 再点击目标位置完成走棋。
5. 如果走法不符合象棋规则，程序会提示非法走法，棋子不会移动。
6. 红黑双方轮流走棋。
7. 点击“重新开始”可以重置当前棋局。

### 3.2 局域网联机对弈

1. 两台电脑需要连接到同一个局域网。
2. 一台电脑点击“创建房间”，作为红方。
3. 另一台电脑输入创建房间电脑的局域网 IP 地址。
4. 点击“加入房间”，作为黑方。
5. 连接成功后，红方先行。
6. 一方走棋后，另一方棋盘会自动同步。
7. 如果需要结束联机，可以点击“断开连接”。
